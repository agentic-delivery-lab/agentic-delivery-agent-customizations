# Primitive decisions

This directory contains decisions local to the Agentic Primitives bounded
context. Architecture Authority is the canonical source for organization-wide
decisions. The ADP-0001 file here is a pinned reference to its canonical
Architecture record; it does not copy that decision text. New local records
cover only decisions that remain specific to primitive packaging, metadata,
capability policy, and projection mechanics.
