# Primitive decisions

Architecture Authority owns all formal ADR, ADP and ADD decision text,
including decisions specific to Agentic Primitives. Context-specific scope
does not create a second canonical decision source here.

This directory may contain pinned references and implementation notes about
primitive packaging, metadata, capability policy and projection mechanics.
Implementation notes must not introduce formal decision records or a competing
numbering scheme. Use the architecture-decision skill and its verified
Authority tracking Issue for formal changes, then consume the approved
Architecture Release through the exact pin in `manifests/primitive-release.json`.
The ADP-0001 file here is a reference only; it does not copy decision text.
